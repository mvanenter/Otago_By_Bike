# Otago by Bike

**30DayMapChallenge · Day 24 · Network**

An interactive ride from Cromwell to Waihola, following Lake Dunstan, the Clutha River / Mata-Au and the Clutha Gold Trail. The rail trail branch runs from Alexandra towards Middlemarch.

## Explore the map

Rename the supplied HTML file to `index.html` and open it in a browser. The map is self-contained.

- Select **Play ride** to follow the bike and boat. Drag the journey slider or choose a trail stage to jump along the route.
- Use **Follow the ride** for a moving camera and **View full network** for the overview.
- Select a trail on the map or use **Test a link** to see what disconnects when that link is removed. Try the boat transfer between Doctors Point and Shingle Creek. Thicker links serve more node pairs whose only connection depends on that link.

[Watch the 17-second route preview](./Otago_by_Bike.mp4)

## Distance and elevation

The mapped journey covers approximately **208.9 km by bike** and **11.8 km by boat**, with **about 1,760 m of modelled cycling ascent**.

Distances were measured along the mapped lines in NZTM2000, so they may differ from operator figures. Elevation was sampled from Copernicus GLO-30 at 50 m intervals and smoothed with a seven-sample median filter. The ascent estimate excludes the boat transfer. The elevation model can differ from the trail surface at bridges and tunnels.
